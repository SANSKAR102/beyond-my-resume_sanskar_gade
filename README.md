# Beyond My Resume — Sanskar Gade

A responsive, single-page portfolio recreated from the screenshots of the original Emergent preview.

## Run locally
No build tools or package installation are required.

1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish for free with GitHub + Vercel
1. Create a new public GitHub repository, for example `beyond-my-resume`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In Vercel, choose **Add New → Project**, import the repository and deploy.
4. No build command is needed. The output directory is the repository root.

## Before submitting
- Test every section and link on desktop and mobile.
- Confirm the project descriptions accurately match the current live versions.
- Add a real resume PDF only if you want a direct resume download. The current Resume links open an email request instead of pointing to a missing file.
- Record your own 3-minute walkthrough and upload it to a public video link.
- If you make further edits with Wispr Flow, describe only what you actually did in the challenge recording.

## Files
- `index.html` — page content and sections
- `style.css` — layout, responsive design, colours and animations
- `script.js` — mobile menu, scroll progress, reveal effects and email form
